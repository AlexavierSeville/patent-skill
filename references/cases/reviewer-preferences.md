# 审批人偏好档案

> **用途**：按审批人沉淀"个人口径类"审核偏好，让上一案挨过的批在下一案首条批注出现前就被读到。`rules.md` 阶段读取表已将本文件列为**权要一稿与全文一稿的必读核心**。
>
> **入档纪律**（唯一出处 `revision.md` 学习闭环）：①每条记录"偏好一句话 + 首次出现的批注原文摘录 + 升格状态（已升格→规则编号 / 待升格）"；②重申类批注（"说过很多次"等）入档时同步触发即时升格；③案件级约定（署名、条数上限、命名）走项目 memory，不进本档案；④本档案是规则的**前哨与索引**，不是规则本体——与规则冲突时以规则文件为准。
