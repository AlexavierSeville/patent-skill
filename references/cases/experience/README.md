# 撰写者经验档案目录（experience/）

一人一档：`xxb.md`（夏晓贝↔桦笙）、`wpy.md`（王培元↔王工）、`lxl.md`。撰写者由案件路径一级目录自动识别（G1），当前案件**只必读本撰写者档案**，其余不默认读（读取表见 `rules.md`）。

## 条目模板（强制五字段）

每条经验必须给全：

1. **偏好一句话**：可执行的规律陈述（"做什么"）。
2. **批注原文摘录**：审稿人批注原句 + 锚点选区（批注选中了哪段文字）。
3. **含义解读**：审稿人亲笔改动的改前→改后 diff（如有）+ 他为什么这么要求。**禁止只抄批注一句话**——判断依据永远是锚点上下文与亲笔改动，不是孤立转述（"充分理解审批意见的含义，而不是片面的"）。
4. **适用边界**：通用写作规律 / 仅本领域 / 仅本审稿人个人口径。
5. **升格状态**：已升格→规则编号 / 待升格 / 不升格（纯个人口径，留档即可）。

## 纪律

- 入档动作挂 `revision.md` 学习闭环：每次返修收尾由 AI 依据锚点上下文+亲笔改动产出条目。
- 通用项由仓库维护者升格进 `references/rules/`（受锚点守卫、scoring 摘录守卫与测试保护），升格后回标状态；个人口径不进共享规则层。
- 案件级约定（署名、条数上限、命名）走项目 memory，不入本档案。
- 案件原始文件（交底书/DOCX/批注稿）一律不进仓库。
- 协作围栏：非维护者仅允许修改自己的 `experience/<自己>.md`（CI 路径守卫强制）。
